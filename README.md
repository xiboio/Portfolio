# Murilo Freitas — Portfolio

Site em inglês com botão para português, contato e projetos Car Detail e urna eletrônica. Inclui estágio atual de TI na Romi, desenvolvendo automações e sistemas com Python, Node.js, React e SQL. O bot incompleto foi removido.

## Abrir

Abra o index.html da raiz no navegador. O site incorpora React, Anime.js e CSS e não exige instalação. Links externos precisam de internet; as fontes do Google têm fallback local.

## Publicar no GitHub Pages

Envie os arquivos para seu repositório. Em Settings → Pages, selecione Deploy from a branch, sua branch principal e a pasta / (root). O arquivo index.html da raiz já está pronto para publicação.

## Editar o código

Os arquivos editáveis estão em source/. Use Node.js 24 LTS. Dentro de source/, execute npm ci e npm run dev.

Após editar, execute npm run standalone dentro de source/ e copie source/standalone/index.html para index.html na raiz. Textos ficam em source/src/translations.js; projetos e contato em source/src/content.js.

A experiência na Romi foi informada pelo titular. Não foram presumidas datas, métricas ou projetos internos da empresa. Os projetos publicados contêm links para os repositórios públicos, sem alegação de uso comercial.

A seção Sobre inclui início do estágio na Romi em agosto de 2026; técnico em Desenvolvimento de Sistemas na ETEC concluído em 2025; bacharelado em Sistemas de Informação na FHO, com conclusão prevista para dezembro de 2029. O botão de currículo baixa curriculo-murilo-freitas.pdf na versão em português e murilo-freitas-resume-en.pdf na versão em inglês. Mantenha os dois PDFs junto do index.html ao publicar.
